# Contributing

Thanks for your interest in improving Gradient DropConnect!

## How to contribute
- Fork the repo and create a feature branch.
- Make focused changes with clear commit messages.
- Ensure code runs (training scripts) and docs build (README links, images).
- Open a Pull Request describing the motivation and changes.

## Development notes
- Python 3.8.12 recommended; install deps via `pip install -r requirements.txt`.
- Keep doc examples minimal and runnable.
- Prefer small, incremental PRs.

## Reporting issues
- Use descriptive titles and include: dataset, model, command line, logs, env info.
- If visual, attach a small screenshot in `assets/screenshots/` when applicable.
