# Screenshots Guide

Store images under `assets/screenshots/` so they render in the README.

Suggested screenshots:
- training_curves.png: Loss/accuracy over epochs for one dataset
- cifar10_results.png: Compact results table
- norb_samples.png: Sample batch visualization
- gradient_mask_heatmap.png: Visualization of gradient-based masks

Tips:
- Use small resolution (<= 1400px width) and compressed PNGs.
- Name files descriptively and use lowercase with dashes/underscores.
